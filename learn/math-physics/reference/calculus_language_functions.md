# Functions Refresher

## Key Concepts

### Function Basics
- Domain and range
- Composition: $(f \circ g)(x) = f(g(x))$
- Inverse functions: $f^{-1}(f(x)) = x$

### Common Functions
- Polynomials (degree, roots, behavior at infinity)
- Rational functions (asymptotes)
- Exponential: $e^x$
- Logarithmic: $\ln x$
- Trigonometric: $\sin, \cos, \tan$ and inverses

### Properties
- Even/odd functions
- Periodic functions
- Continuity
- Boundedness

### Transformations
- Shifts: $f(x - c)$, $f(x) + c$
- Scaling: $cf(x)$, $f(cx)$
- Reflections: $f(-x)$, $-f(x)$

## Quick Review Questions
1. Find the domain of $f(x) = \frac{1}{\sqrt{x - 1}}$
2. If $f(x) = e^x$ and $g(x) = \ln x$, what is $(f \circ g)(x)$?
3. Sketch $y = \sin(2x + \pi)$ — what are amplitude, period, phase shift?
