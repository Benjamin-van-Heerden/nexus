this command is concerned with, like the name implies, self-improvement, i.e. habit tracking (both positive and negative), and will be more bespoke since I want to include a way to create habits like e.g. mental math practise, whereby the agent would prepare for me a simple file with a few calculations and equations to solve and track, my accuracy, speed as well as ramp up the difficulty appropriately when I am getting noticably better. Reading is also a very important habit for me so the system we put in place for it should be sufficiently complex so as to capture reading frequency, comprehension etc. The other important habit is exercise and here I want the agent to act like a 'hype man' - tracking, motivation, and critique when I fall short
