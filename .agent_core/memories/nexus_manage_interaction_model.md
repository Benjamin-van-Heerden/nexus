Nexus manage runs in a long-lived session (cleared weekly). Fresh session = full onboard, otherwise refresh. Runs once daily in the morning. Purpose: report what's happening today (tasks, events, calendar) and absorb new input anytime (new tasks, todos, events, contacts). It is informational/administrative — not coaching. The agent reports, the user schedules and creates. No back-and-forth exercise loop like learn/self.
