Nexus learn runs once daily in the morning. Session is flushed twice per week. Fresh session = onboard, otherwise refresh. The agent composes exercises (theoretical reading + practical pairing by default), sends them to the user, then STOPS and WAITS. The user does the work and reports back — the agent gathers feedback (duration, difficulty, struggles), handles edge cases (broken exercises, redos, partial completion), marks tasks complete, creates a learning record capturing what was done and what should come next. Then stops again. No new exercises until next session's onboard/refresh.
